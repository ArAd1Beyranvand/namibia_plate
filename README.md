# namibia_plate

Namibia's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the yellow standard series in every digit count and town-code length, the blue-on-white personalised plate with its flag, the red diplomatic and the green government plates (GRN, POL, NDF and the other prefixes), with their themes, alphabets and advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:namibia_plate/namibia_plate.dart';

PlateCanvas(
  spec: NamibiaPlates.windhoek,
  theme: NamibiaThemes.standard,
  validator: const NamibiaPlateValidator(),
  autoValidate: true,
);
```
